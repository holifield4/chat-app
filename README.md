# Chat App

Chat app with Socket IO

## Tech Stacks
### Backend
- (Socket.IO)[https://socket.io/]
- ExpressJS
- NodeJS
- TypeScript

### Frontend
- ReactJS
- Vite
- TypeScript
- Zustand
- Tailwind
- (Flowbite-React UI Library)[https://flowbite-react.com/]

## Getting Started
1. Install all dependencies for both chat-server and chat-client

```js
    npm install
```

2. Configure all secrets in .env file (refer to .env.example)

3. Run both applications

```js
    npm run dev
```

4. Explore the app by accessing the frontend local server in port 4000

5. Login multiple users in multiple browsers (or you may use incognito mode) and start chatting
